# Puff健身 App 原型

Puff健身是一款专注于健身训练的移动应用原型，旨在帮助用户管理训练计划、记录训练数据并提供AI智能辅助，实现个性化健身体验。

## 功能特点

### 核心功能
- **训练计划管理**：创建、编辑和管理个性化训练计划
- **AI智能助手**：基于语音输入生成个性化训练建议和计划
- **训练记录**：记录训练过程和表现数据
- **个人中心**：用户资料管理和训练数据统计

### 页面模块
1. **首页**：当日训练计划和概览
2. **训练计划**：查看和编辑训练计划详情
3. **AI助手**：获取个性化训练指导和建议
4. **个人中心**：用户信息和训练数据统计

## 技术栈

- **前端框架**：HTML5, Tailwind CSS, JavaScript
- **图标库**：Font Awesome
- **UI设计**：响应式设计，玻璃态卡片风格

## 项目结构

```
puff_chat_prototype/
├── index.html          # 主页面，展示所有原型页面
├── README.md           # 项目说明文档
├── prompts.md          # AI提示词文档
└── pages/              # 各功能页面
    ├── home.html           # 首页
    ├── workout.html        # 训练计划页面
    ├── ai-assistant.html   # AI助手页面
    ├── profile.html        # 个人中心页面
    ├── notifications.html  # 通知设置页面
    ├── workout-session.html # 训练计时页面
    ├── workout-plans.html  # 训练计划列表页面  
    ├── workout-edit.html   # 编辑训练计划页面
    └── profile-edit.html   # 编辑个人资料页面
```

## 界面特点

- **现代化UI**：采用玻璃态卡片设计，视觉效果现代简约
- **响应式设计**：适配不同屏幕尺寸
- **流畅交互**：平滑的动画和转场效果，提升用户体验
- **个性化主题**：蓝紫色调为主色调，简洁明了的界面布局

## 使用指南

### 查看原型
1. 直接打开`index.html`文件，可以看到所有模块的原型展示
2. 点击各个模块的iframe可以单独查看对应功能页面

### 开发指南
1. 使用任何现代浏览器打开HTML文件即可预览
2. 本原型使用CDN引入Tailwind CSS和Font Awesome，需要联网使用
3. 可以直接编辑HTML文件修改界面和功能
